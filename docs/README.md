## The shape of the thing

TM requires two independent proofs on every request, and almost everything else follows
from that:

1. **An OAuth2 bearer**, proving your *application* is approved for API access. It comes
   from DWAB's token endpoint, or from a broker like Cerberus holding those credentials on
   your behalf.
2. **An HMAC-SHA256 signature**, proving the *event partner* has authorised this
   particular install against their TM instance. The key is generated by TM and is per
   event.

A bearer without a signature is an approved app nobody invited. A signature without a
bearer is an invitation to an app that was never approved. TM wants both.

Everything fallible returns `Result<T>` rather than throwing, because these failures are
frequent, expected and operator-actionable — a venue's internet drops, a laptop's clock
drifts, an event partner forgets the checkbox. Exceptions are reserved for wiring
mistakes you cannot recover from at runtime (`TmConfigError`).

## Two things worth knowing before you build

**The field set websocket cannot run in a browser.** TM signs the socket's HTTP upgrade,
and the WebSocket spec forbids setting handshake headers from JavaScript. This is
structural, not a missing feature. REST works anywhere; the socket needs Node, Bun, or a
runtime you can hand a custom transport.

**A timeout is a match event with an empty body.** TM reports timeouts as
`fieldMatchAssigned` with an empty `match` object and no type tag. Every correct
implementation of this API has had to detect it by counting keys. If you parse events
yourself rather than using `reduceFieldsetState`, you must too.

## Why this package exists

The reference implementation, `vex-tm-client`, was unpublished from npm and its repository
deleted on 2026-08-26. By then the same logic had been vendored into three projects and
reimplemented once in C++, and the copies had started to drift. This is the canonical
implementation those projects move onto, and it fixes two bugs confirmed in the surviving
upstream source — a 401 that left a rejected bearer cached for up to an hour, and a
missing single-flight guard that let concurrent cold-start calls each mint their own
token.

See [migrating](migrating.md) if you are on one of those copies.
